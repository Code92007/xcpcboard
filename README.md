# XCPC Board · 一起看比赛

可复用的 XCPCIO / CCPC 观赛看板，无前端构建依赖，后端只需要 Python 3.10+ 标准库。

线上看板：<https://xcpcboard.wannafly.cn/>，HTTP 入口会自动跳转到 HTTPS。

## 使用

```sh
export ADMIN_TOKEN='replace-with-a-long-random-secret-at-least-20-characters'
python3 server.py
# http://127.0.0.1:8766
```

点右上角「管理赛站」，输入 `ADMIN_TOKEN`：可编辑赛站标题、榜单链接、B 站直播和视频播放列表、封榜时间及是否置顶，或新增其他赛站。武汉当前使用 2026 年 11 月 1 日正式赛链接，默认置顶在最左侧；CCPC 女生赛固定排第二位，不受正式赛数据是否发布影响，其余赛站按置顶状态及上游比赛开始时间从近到远排列（尚未读取到时间的排在后面）。西安、长春和成都保留现有配置。链接支持 `?group=official` 等原榜排名分组。

武汉已沿用原赛站接入[正式赛榜单](https://board.xcpcio.com/icpc/51st/wuhan?group=official)，从 `wuhan-warmup` 核对队名和学校后继承关注、分组和备注，并重新启用正赛封榜保护。新安装默认使用正式赛；已有部署在武汉的「管理赛站」替换「榜单链接」并保存即可，升级不会覆盖已配置的链接。浏览器打开武汉正赛时会自动复制本机热身赛的个人关注和备注，热身赛原数据保留。

「CCPC 女生赛」已沿用原赛站接入[第十二届成都女生专场正式赛](https://rank.iccpc.cn/r/e5697b3a-8326-4818-84ca-e2ce1688af23)，保留[热身赛](https://rank.iccpc.cn/r/6277d913-846a-4259-92a5-f61bf54c0783)的原始快照、关注、分组和备注。11 月 1 日切换时，官方已发布正式赛入口，队伍和榜单数据尚未公布；后台会持续同步，首次获得正式赛数据后核对同年同名赛事、队名和学校，再自动继承公共设置和当前浏览器中的个人关注及备注，兼容队伍 ID 变化。正式赛已有设置优先，跨年份或其他赛事不会自动继承。新安装默认使用正式赛，已有部署需在「管理赛站」替换链接；升级保留自定义配置。

- 点 ☆ 加入个人关注；「关注分组」创建浏览器本地分组。个人分组和个人备注仅存 localStorage，无需登录。
- 「我的关注」旁的「勾选导入」（或榜单上方「选择关注」）可批量勾选队伍，支持搜索学校、队名和备注，筛选已选 / 未选队伍，以及从当前赛事已有公共或个人分组添加；搜索后可「全选当前列表」，一次选中整所学校的队伍。保存后进入「我的关注」，取消时保留原关注。
- 「导入关注」可从当前浏览器曾关注过的其他赛站导入同名队伍；导入前可核对并取消勾选。重名无法唯一匹配的队伍会跳过，已关注队伍不会重复添加。
- 新建或编辑分组时，可切换「仅看我的关注」，从已关注队伍中勾选一部分；也可在「从已有分组添加队伍」里选择「我的关注」整组添加，或从公共/个人分组添加。支持「仅看已选 / 仅看未选」、全选当前列表和一键全不选；点击保存才会生效。
- 排名与提交队列的金银铜底色按完整正式队伍榜计算，打星队伍不计奖；XCPCIO 读取上游奖牌名额，ICCPC 读取上游比例、名额模式及过题/提交/全部队伍的计奖基数。关注分组不改变奖牌线。
- 管理员可创建公共分组、指定新访客默认视图，填写所有访客可见的群员备注。个人备注优先于公共备注。
- 切换原榜组会改变官方排名口径；个人/公共关注筛选不会重排名次。
- 榜单默认完整展开，直接随页面向下滚动。桌面窗口（至少 960px）中的多题榜单会自动压缩列宽、换行长队名与备注，让 A–M 一屏显示；较窄桌面会将提交队列放在榜单下方。
- 「群友备注」与「队伍 / 学校」之间默认显示上游提供的座位号（如 C04），上游未提供时显示 —。搜索栏旁的「显示座位号」可随时隐藏或展示，本浏览器会跨赛站记住选择。
- 分组和备注按榜单路径保存。XCPCIO 同一赛站从 `…-warmup` 切到 `…` 正式赛时，核对队名和学校后自动继承公共分组、备注及当前浏览器中的个人关注；队伍 ID 变化时仅匹配唯一的同名同校队伍。保留正式赛已有设置和热身赛原数据，只导入一次，后续取消关注不会被重新加回。其他赛站和年份仍独立保存。
- 每个赛站可配置最多 20 个 B 站直播或普通视频，支持房间号、BV/av 号、完整链接与视频分 P，管理员可编辑名称、调整顺序、删除。有内容时默认展开，用户收起后在本浏览器记住选择。播放器背景为黑灰色，iframe 随容器铺满。访客通过节目按钮、左右箭头、键盘或播放器下方的滑动区切换；不自动轮播以免打断观看。只有当前节目创建 iframe，切换、收起或离开赛站时停止旧播放器；榜单轮询不会重载当前播放器。嵌入受限时可打开 B 站原页面。
- 新提交依次滑入右侧队列，判题结果更新也会重新入队。队列显示当前排名、队名、学校、备注、题号、结果、当前 AC 数和提交时间，可暂停并仅看当前分组。首次加载显示近期真实提交，不将历史伪装为直播。

## 数据与缓存

研究依据为 [XCPCIO 公开数据](https://board.xcpcio.com/icpc/51st/xian-warmup?group=official) 和 [上游 core 实现](https://github.com/xcpcio/xcpcio/tree/main/packages/libs/core/src)。服务端直接读取 `config.json`、`team.json`、`run.json` 和配置引用的学校数据，兼容旧 `problem_id` 和新版 `problems`、多语言队名、秒/毫秒时间戳。罚时忽略 CE/PE 等上游不计罚时结果，支持按秒、按题取整到分钟或汇总后取整，按解题数、罚时、最后解题分钟排序，平分共享名次。

CCPC 数据源读取 `https://rank.iccpc.cn/upload/outrank_attach/<榜单ID>/rank.json`，北京时间解析 `time_context`。实现对照 [CCPC 页面源码](https://rank.iccpc.cn/static/ojweb/csgoj/contest/rank_ccpc.js) 和 [计分核心](https://rank.iccpc.cn/static/ojweb/csgoj/contest/rank_core.js)：CE 不罚时、PE 罚时，累计秒数后统一向下取整到分钟，排名不使用 XCPCIO 的最后解题时间规则。没有提交的注册队伍也可提前关注。

长春达到 `ccpc_meta.threshold`（目前 50 队）才揭晓题号；未揭晓题目按队内 AC / 提交时间排列，不能跨队对齐，不显示隐藏题目的 ID、题号或首杀。队列以 `?` 表示未揭晓题。揭晓计数基于全榜去重队伍，与关注视图无关；题号全公开只服从上游 `view=referee` / `frozen_show_all` 标记，不根据本地时钟推测映射。开赛前公开题目为空是有效快照，总题数从元数据读取。

后台每 15 秒抓取提交（可通过 `POLL_SECONDS` 调整，最短 10 秒），元信息约每分钟重新校验，支持 ETag/Last-Modified。访客只读取统一缓存，不会按人数放大上游请求。同一秒内复用计算、JSON 序列化和 gzip 结果，配置或快照更换立即失效；视频流由浏览器直接访问 B 站，不占本服务器视频流量。

成功的完整原始快照 gzip 压缩后原子落盘，保留最新和上一次变更快照。网络错误、超时、数据异常或突然空榜会保留成功缓存并标记过期。进程重启会从磁盘恢复，最新文件损坏时尝试前一份。浏览器另外保留最近成功的可展示快照，连接服务失败时继续显示。

默认开赛 4 小时封榜，若上游更早封榜则采用较早时间。封榜后的原始结果在服务端统一替换为 `FROZEN`，榜单与提交 API 都不泄漏隐藏结果。比赛结束后继续保留封榜；管理员确认官方已公开最终结果后可手动解封。上游本身没有公开的结果无法恢复。队列 API 保留最近 800 次提交，隐藏标签页暂停前台轮询。

已结束且封榜的比赛在横幅提供「揭榜」按钮，登录管理后可显示上游已公开的最终结果；「管理赛站」中的手动解封选项仍可使用。切换到另一榜单（例如热身赛换正式赛）会自动重新启用封榜保护，避免沿用热身赛的揭榜状态。没有播放内容时，「直播 / 视频」会弹出明确说明和配置入口。

配置和原始快照位于 `DATA_DIR`（默认 `data/`），不提交到 Git。管理密钥只放环境变量，前端仅在当前标签页 sessionStorage 保存；不要在链接中携带密钥。

## 部署

`deploy/` 提供 systemd、Caddy 域名站点及保留旧 `:8082` 入口的 Nginx 配置。生产目录 `/root/xcpcboard`，服务名 `xcpcboard.service`，后端监听 `127.0.0.1:8765`。

```ini
# /root/xcpcboard/.env (chmod 600)
ADMIN_TOKEN=replace-with-random-secret
BIND=127.0.0.1
PORT=8765
DATA_DIR=/root/xcpcboard/data
POLL_SECONDS=15
```

更新程序文件时保留 `data/` 和 `.env`，然后 `systemctl restart xcpcboard`。DNS 将 `xcpcboard.wannafly.cn` 的 A 记录指向 `43.155.179.39` 后，Caddy 会自动申请 HTTPS 证书。不要把旧版 Nginx 的静态根目录配置继续用于新版，以免暴露非静态文件。

旧邀请赛界面保留在 `/legacy/`，原 Node 服务代码作为历史实现保留在 `legacy/server.js`。线上替换之前需备份原部署文件与代理配置，停止原 Node 进程，使用 systemd 接管。
